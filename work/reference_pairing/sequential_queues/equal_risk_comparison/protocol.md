# Equal-budget, equal worst-case risk comparison

Frozen before this comparison: all 20 targets in `new_target_test` and all 7 targets in `loss_cap_holdout`, at the same pre-existing 10% record budget and all ten source seeds per target. These targets were previously examined for related strategies and are not an independent prospective test. Both methods use source-random top-B as default, source-difficulty top-B as alternative, and k=floor(.05*B). Explore only alternative items outside the default top-B, in exactly the same alternative ranking order. Method fixed-k checks at most the first k outside items, then fills remaining slots from the top of the default queue. Method feedback checks outside items until the number with no discrepancy reaches k or the outside queue is exhausted, then fills remaining slots from the same default ordering. For k=0, both take only the default. Each record is reviewed once and counts toward B. Fixed-k and feedback both have the identical deterministic worst-case shortfall upper bound k vs the default, but their actual numbers of nondisagreement reviews and actual shortfall can differ. A bound relative to interleave is not claimed. The source candidate index is taken from previously saved source selection only; all unreviewed target labels are hidden from the two methods.

Report both methods' total paid discoveries, feedback minus fixed-k, the extra number of alternative-only reviews, actual nondisagreement count, and direct/interleave baselines on each target and each seed. Verify budget, deduplication, worst-case bound and no unpaid-label access, including flipping all unchecked labels. Evaluate all 270 target/source panels, keep negatives. Group-bootstrap intervals for fixed output comparisons are descriptive only: resample archived target record groups holding each output queue fixed and average over the ten existing source seeds; repeated source seeds share the target corpus, and related Snow/CrowdTruth tasks share families. Also include a B<=20 stratum count to expose no-exploration cases. Reviewer votes, reference creation, source evaluation and computation are outside B; equal number of records is not necessarily equal voting or monetary cost.
