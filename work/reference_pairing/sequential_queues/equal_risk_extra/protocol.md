# Frozen equal-risk comparison on six additional archived targets

Defined before inspecting these outcomes. Targets: NoisyAG-News (ag), PGR, nli_dnc, nli_mnli, nli_snli and snow_rte. All ten archived 10% source seeds per target; B=round(0.1 N), k=floor(.05 B). Use the exact fixed-k and paid-feedback algorithms from equal_risk_comparison/run.py, with random-source choice as default, difficulty-source choice as alternative, the same candidate ranking and same within-candidate order. Also score direct default and item-interleave. The checked records are disjoint and all paid from B; no labels except checked records affect the feedback decision. Evaluate every case including identical candidates and k=0. The archived ag/pgr arrays have named candidate indices and other four use numeric indices. Source choices are read from source selection fields, not target outcome fields. 60 source panels, 120 method traces; all outputs are reported.

These six datasets did not enter the earlier 27-target equal-risk comparison, but were previously used elsewhere in this research, so this is a supplementary within-project comparison, not a fresh prospective test. Their seeds reuse one target corpus each; the NLI-related datasets are not presumed independent. Error means disagreement with the archived reference, which can be an expert, another human annotator, or a dataset reference, not an automatic claim of objective error. Equal review records are not necessarily equal human votes; source selection, reference labels, model preparation and votes are excluded from B. All 10 seeds for a given target use the same target corpus and rankings. Bootstrap over archived record groups on fixed output queues is descriptive conditional on the selected queues and does not rerun policy decisions.
