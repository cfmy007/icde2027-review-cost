# Tightness and usefulness of review-loss bounds

Fixed before this analysis. Use all 33 archived target datasets and all 10 source choices each from the already completed equal-risk comparisons. Reuse exactly the same target ranking arrays, source-random as default, source-difficulty as alternative, and B=round(.10*N). These are previously explored datasets and source choices; this is a retrospective descriptive analysis, not a new external validation. Target disagreement is defined by each dataset's archived reference label.

Bound 1: For equal-length default and alternative prefixes, d=|A\C|=|C\A| is observable without target labels. Compute actual absolute yield gap G=|Y(A)-Y(C)| only retrospectively, slack d-G, and tightness G/d when d>0; report d=0 separately. Before observing any outcomes, define three practically interpretable tolerance thresholds of d/B <= 1%, 5%, and 10% (absolute allowable difference per check). Report the number of panels and target-level macro summaries; panels share each target and related data sources so counts are not independent successes. Report actual target gap distribution without treating the label-free bound as a forecast of its sign. Do not use target labels to filter targets or choose thresholds.

Bound 2: Use exactly the existing 5%-of-B risk-cap feedback policy (k=floor(.05B)) and fixed-k comparator. For each panel compute observed non-disagreement f on paid alternative-only checks, actual signed default shortfall D=Y(A)-Y(S), nonnegative loss max(0,D), looseness k-max(0,D), a posteriori deterministic bound f and f-max(0,D), plus number of alternative-only reviews. Check D<=f<=k and fixed-k D<=k. Separate k=0, d=0, and cases where no alternative item is inspected; report whether k is hit and compare actual gain/loss vs default and interleave. The deterministic worst-case bound uses no assumptions on future outcomes beyond consistent binary record-level discrepancy and equal costs; it does not guarantee positive net gain, accuracy improvement, or any bound relative to the interleave strategy. The tighter f is observed after paid checks, not available before them.

Report paired source-seed distributions per target, as well as per-target-weighted proportions rather than treating 330 panels as independent datasets. Exclude zero denominators explicitly for ratios and report their counts. Source evaluation, reference label collection, multiple reviewer votes, and detection compute are not included in B; reference disagreement is not always objective error.
