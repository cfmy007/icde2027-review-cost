# Pre-run diagnosis of the paired replacement pilot on SBIC and NoisyAG-News

Fixed before running this diagnostic. These two targets are selected because the previous exploratory study showed overprediction conditional on choosing replacement. They are previously inspected targets, not held-out data; no claim of independent validation. Use all ten archived source seeds and the same 30 per-panel pilot random seeds as the previous pilot. Budget B=round(.1N), same default/alternative, replacement candidate Q1 and m<=floor(.2B), with already-reviewed pilot records retained and included in B. Use the same Beta(1,1) rule and exact same completion rule as the earlier experiment.

The primary analysis reproduces the previous two-percent-per-side uniform pilot and decomposes its prediction error exactly. For each actual pilot, construct the two possible completed review sets. For the records on which those sets differ, write the predicted gain as signed counts times the pilot group posterior mean. In hindsight compute (a) the same signed counts times the raw pilot mean, (b) times the full fixed replacement/tail group means, and (c) the actual signed sum on the differing records. Their successive differences give smoothing contribution, sample-versus-full-group contribution, and full-group-versus-actually-differing-position contribution. This is an algebraic retrospective accounting; the last term is affected by the sampled records as well as ordering, and the terms are not independently randomized causal effects. Full-label quantities are never available to the policy.

Compare unconditional results with results conditional on the model selecting replacement; report selected fraction, predicted and realized gains and calibration error. Selection conditioning is not by itself a proof of a causal winner's curse: pilot observations affect both forecast and completed sets.

Follow-up, specified before outcomes: compare side sample sizes floor(.02B), floor(.04B), floor(.08B), with at least one per side and capped by m; for each compare uniform random sampling against equal allocation between early/late halves of each fixed ordered group. When odd, early half gets one more where available. All paid records count toward B, are retained and affect the completed sets. Rank-aware forecasts use Beta(1,1) posterior means within each half; an unsampled half uses its prior. All conditions reuse the same per-panel rep seeds; sample selections differ between sampling designs and sizes. The 8% each-side design can spend 16% of B. Report m, actual pilot cost, selection rates, predictive absolute error, final hits, difference against pilot-then-default, full direct review, item interleave, fixed-k and loss-cap feedback. These changes simultaneously alter pilot information and the fraction of budget already committed, so gain is always assessed at equal total B. No oracle means enter real decisions; full reference labels used only in post hoc diagnostics. Verify label blindness, unique reviews and same budget per source panel and condition.

All 30 pilot repeats share each target corpus and saved rankings, and the ten source-choice seeds also share target records. Comparisons characterize random sampling in these two fixed datasets, not independent datasets. No inference that the rank-aware variant or larger pilot will work generally. Reference creation, source selection, multiple votes and model computation are not included in the equal-record budget.
