# Frozen evaluation: new-to-rule human-annotation targets

The 0.05 switching policy from `../switching.py` is frozen without modifications: B=round(0.10*N), batch=max(1,floor(.02*B)), review first batch of source-random queue then source-difficulty queue, choose difficulty for the next batch only if its latest observed mean exceeds default by strictly 0.05, otherwise default; retain last 100 observed hits per chosen arm, skip duplicates, finish at exactly B unique records. Same candidate prefixes are used by direct source-random, deduplicated item-interleave and the switching method. No policy parameter or target selection changes after outcomes are inspected. The second source queue's direct value is included as a descriptive comparison, not used to select the method.

Fixed target catalog: all 19 pre-existing `inputs/new_crowd` directories other than nli_dnc, nli_mnli, nli_snli and snow_rte, plus `inputs/heldout_pico`. These targets were not part of `staged_review.cases()` or the earlier 0.05 switching experiment used to choose this rule. They have been used in earlier, separate studies in this workspace; therefore they are new to this rule, not wholly unseen independent prospective datasets. Snow emotions and CrowdTruth tasks share families and are not treated as independent datasets. Human judgments are measured against each archive's recorded reference, which may be majority, expert, a second annotator, provenance or another proxy; the resulting discrepancy is not universally an objective error.

For each target use all ten pre-existing expanded-menu 10% source seeds in paired.csv. `random` and `difficulty` are choices made on their respective source synthetic evaluation protocols, not target-label-selected detectors. The saved ranking arrays are the same for all seeds; these seeds vary source-protocol choices, not independent target samples. Target labels are revealed to the adaptive method only for reviewed items, then used offline for comparisons. Paired group-cluster bootstrap resamples archived record groups on fixed output queues, holding all source-seed choices and adaptive decisions fixed; intervals characterize retrospective finite-corpus contribution variability under that resampling scheme, and do not represent repeated target datasets or fully rerun adaptive-policy sampling. No interval is supplied if only one group. Vote counts and source/reference construction costs are not included in B; B is equal number of reviewed records, not necessarily equal human votes. No training, label or target selection can use unseen target reference data.
