# Fixed loss-cap follow-up

Defined after inspecting `new_target_test` results, hence this is exploratory on the same 20 targets, not new holdout validation. Take the existing default and alternative top-B prefixes. Check alternative-only records in their original order, counting every checked record toward B; stop taking such records when floor(.05 B) reviewed alternative-only records have no disagreement with the reference label, or no alternative-only records remain. Fill the remaining budget from the default prefix in order. If floor(.05 B)=0, take only the default. Each paid outside record stays in the final B checks. No unchecked label is used for decisions. The default's missed hits cannot exceed the number of outside records with no disagreement, hence default yield minus this strategy's yield is deterministically at most floor(.05 B), with unit record costs and consistent binary adjudications. The bound does not imply positive gain or bound losses to interleave. Compare default, interleave, prior fixed switching, and this rule on the identical sources and budgets. These targets were examined previously; no target selection or threshold adjustment is made after this protocol.
