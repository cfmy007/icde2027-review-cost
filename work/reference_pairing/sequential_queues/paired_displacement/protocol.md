# Budgeted paired displacement pilot

Frozen before this run. On all 33 previously archived targets in `equal_risk_comparison` and `equal_risk_extra`, use their original ten source seeds, random-source detector as default, difficulty-source detector as alternative, and B=round(.1 N) review records. All these targets were previously examined, so results are exploratory, not prospectively untouched holdouts. All choices are based on already archived source selections, not target reference outcomes.

For A=default top B and X=alternative top-B items outside A in alternative rank order, fix m=min(len(X),max(1,floor(.2B))) if X is nonempty; otherwise perform direct default. Construct the proposed queue Q1 by retaining the first B-m default records and adding X[:m]; Q0 is A. The records potentially displaced are the last m records in A. Uniformly sample without replacement s=min(m,max(1,floor(.02B))) items from X[:m] and s from the displaced default tail; these are the paired pilot. The two samples are disjoint, both count toward B and both are retained. A separate seed for each target/panel/repetition is specified by the program, with 30 pilot repeats per panel and no filtering.

For each candidate action Q0 and Q1, form the actual complete review set: all already audited records plus the earliest not-yet-reviewed records of that queue, until B distinct records are reached. Use independent Beta(1,1) pilot posteriors for the two fixed strata. Estimate the conditional difference in hit count by counting which unaudited candidate records differ between the two completed review sets and multiplying these counts by the corresponding posterior mean, adding already-observed items exactly (common audited items cancel). Select Q1 only when its estimated hit count is strictly greater; otherwise select Q0. This requires only paid pilot labels. Because the completed sets depend on sampled records, this rate-based rule is a fixed practical heuristic, not a claimed unbiased or calibrated estimate. There is no risk-cap guarantee for this paired pilot policy.

Same-budget baselines: direct default, deduplicated item-level interleave, fixed-k alternative-only exploration and paid-feedback loss-cap exploration (k=floor(.05B)), and the same paired pilot followed by default regardless of its labels. The target-oracle better choice between the two completed queues is calculated only post hoc for diagnostic regret; it is never used for the decision. Comparing to paired-pilot-then-default isolates the decision after pilot; comparing to full direct and the other policies assesses complete cost including both paid strata. Record actual yield, m, pilot cost, choice, estimated and realized incremental gain, all baselines, and default shortfall. All labels outside reviewed traces are flipped to verify the actual selection and choices are unchanged; strict B unique records and all baseline risk guarantees are checked.

For each of 33 targets use all source panels, including identical queues and tiny budgets. Report 10*30 pilot replays as sampling variation on one existing target corpus, not independent data; related datasets may share source families. Reference labels include expert annotations, majority votes, another annotator, or dataset reference; disagreements are not necessarily objective label errors. Unit of cost is one record; historical source selection, reference collection, multi-vote adjudication, compute and model setup are excluded. Resampling records while fixing output decisions does not validate adaptive policy uncertainty. All comparisons are within-target descriptive and no untuned benefit is assumed.
