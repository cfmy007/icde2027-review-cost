# Fixed 5% default-loss cap on archived human-annotation targets

Fixed before reading this evaluation's outcomes. Use the previously implemented policy in `new_target_test/loss_cap.py` without changing it: budget B=round(0.10*N), cap k=floor(0.05*B). From the difficulty-source top-B queue review its records outside the random-source top-B queue, stopping once k reviewed outside records have reference-disagreement indicator 0 or the outside set is exhausted; retain every outside record and fill the remaining B slots from the top of random-source queue. If k=0 use the default only. Every review is counted once against B. Use all 10 archived expanded-menu source seeds; pre-existing source-derived indices identify candidate queues. Target reference labels are used only when reviewing an item and when scoring after selection; columns describing target outcomes in paired.csv are ignored.

Fixed catalog: AudioSet, Davidson, HateXplain, MBIC, Measuring-Hate-Speech, SBIC and Stanford-Politeness in inputs/historical. These targets are outside the previously recorded simple loss-cap experiment's 13 data sets and outside the 20-target follow-up used to discuss this exact rule. These archives have been used for other experiments in this project, including related loss bounds; they are new-to-this-policy tests, not wholly unseen independent data or prospectively collected targets. Compare directly against the same source-random default and item-level deduplicated interleave. Score all target seeds and keep all outcomes. Report equal-record-budget discovery yield, fraction and count of outside reviews, non-disagreement failures, deterministic default shortfall bound and per-target results. Source seeds reuse the same target corpus; they are not independent targets. Reference determination, source selection, computation and multiple annotator votes are not included in B, so this is equal-record, not necessarily equal-vote, cost. Reference disagreements need not all be true objective label errors.

Exact bound: if m outside items were reviewed and f had no reference discrepancy, the capped policy has at least m-f hits among outside items; replacing m default items can remove at most m hits, so its shortfall from default is at most f <= k. This guarantee does not extend to other cost units, arbitrarily inaccurate or inconsistent adjudication, downstream training quality or the interleave baseline. The strategy does not predict whether sampling will pay off.
