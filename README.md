# Reproducing the review-cost experiments

This artifact contains the archived source selections, target rankings, reference-disagreement arrays, experiment code, per-run predictions and paper tables used by the review-cost study. It replays the paper's review decisions and recomputes the principal downstream statistics without downloading datasets or retraining models.

## Run the replay

Use Python 3.12 and the packages in `requirements.txt`:

```
python -m pip install -r requirements.txt
python reproduce.py
```

The program writes regenerated tables and figures to `outputs/` and prints one result per step. It performs the following:

- reconstructs all 510 source-seed/budget records for the 17 main target collections from saved ranked records and reference disagreements, then checks the two additional collections;
- reconstructs source choices from 2,580 saved source-score vectors;
- recomputes all 20 archived CASIA Table III values and all 99 crossed-study Table V AUC cells from per-run results;
- replays the four review policies on 33 targets and regenerates the loss-cap sweep from the 31-target inputs;
- rebuilds the data for Figures 2 and 3, and replays the paid paired-pilot analysis;
- verifies the saved equal-cost downstream decisions on 400 runs and class-matching decisions on 200 runs;
- recomputes the CIFAR-100N and Wikipedia downstream point estimates and their 2,000-draw paired bootstrap results from saved predictions;
- recomputes the GerMS and ALIA 20% budget comparisons and paired bootstrap intervals from saved predictions;
- recomputes the CIFAR-10N and CIFAR-10H paired downstream summaries from saved per-test-item predictions.

The ten source seeds on a target reuse the same records and trained models. Repetitions of a paid audit share the target corpus. The output is an experiment replay, not an independent replication on new data.

## Files

| Path | Contents |
|---|---|
| `data/` | Measurements and intermediate summaries from the submitted study. |
| `work/decision_closure_20261111/inputs/` | Saved target rankings, reference-disagreement indicators, and source-choice records for the review-policy replay. |
| `work/reference_pairing/sequential_queues/` | Paid review policies, paired pilot, diagnostics, protocols and per-run results. |
| `crossed_study/` | Archived crossed-protocol code, source model checkpoints, split assignments and per-run results. |
| `downstream/` | Equal-cost review receipts, held-out predictions, source choices, fixed representation data for Wikipedia and analysis scripts. |
| `outputs/` | Tables and figures regenerated by the replay. |

`raw_rankings/` contains the selected text and annotation inputs, the AudioSet annotation and VGGish feature records, and code for regenerating 36 text target rankings and the AudioSet ranking. Its README gives the commands and the comparison with the archived rankings. `replay_source_selection.py` starts from stored source-score vectors, and `replay_neighbours.py` starts from pooled per-bin counts. The crossed-study code covers the controlled image study. The downstream prediction replay starts from stored predictions.

## Training from source data

The trained CIFAR model checkpoints and the controlled-study scripts are in `crossed_study/`. Public CIFAR inputs can be downloaded with:

```
python crossed_study/prepare_data.py --cifar all
```

Use `crossed_study/prepare_data.py --gnt /path/to/casia-archives` for the official CASIA GNT archives. CASIA distribution is subject to its provider's terms. `crossed_study/prepare_features.py`, `crossed_study/cross_protocol.py`, and `crossed_study/protocol.json` specify the archived image study. Additional PyTorch, torchvision, pandas and scikit-learn versions and a compatible GPU are needed for training.

For the CIFAR-100N equal-cost training, prepare the already downloaded CIFAR-100 Python data and run:

```
python downstream/prepare_c100.py /path/to/cifar-100-python
python downstream/equal_cost_selection.py c100 linear --out downstream/retrained
```

The frozen source candidate queues and split indices are included. The default torchvision ImageNet weights for ResNet-18 and EfficientNet-B0 are fetched by torchvision if not cached. The training recipe uses CUDA and BF16. `downstream/equal_cost_selection.py wiki linear --out downstream/retrained` uses the saved Wikipedia feature matrix and labels. Training these models was not repeated for this package; model training, dependency versions, GPU kernels and library changes can alter floating-point outputs. The stored prediction replay above is the executed verification for the reported results.

## Public input sources

- CIFAR: https://www.cs.toronto.edu/~kriz/cifar.html
- CIFAR-10N and CIFAR-100N: https://github.com/UCSC-REAL/cifar-10-100n, data revision `49df7d8a69e355470c77c1c2f2424916325a394b`.
- CIFAR-10H: https://github.com/jcpeterson/cifar-10h
- Fashion-MNIST-H: https://github.com/ishida-lab/irreducible
- CASIA handwriting: https://nlpr.ia.ac.cn/databases/handwriting/Download.html
- SNLI: https://nlp.stanford.edu/projects/snli/
- Wikipedia personal attacks: https://meta.wikimedia.org/wiki/Research:Detox/Data_Release
- GerMS-AT: https://huggingface.co/datasets/ofai/GerMS-AT
- Human Detectors (`authorship`): https://github.com/jenna-russell/human_detectors; Russell et al., ACL 2025: https://aclanthology.org/2025.acl-long.267/. The source repository uses the MIT license; its copyright and license notice is reproduced in `raw_rankings/text/HUMAN_DETECTORS_LICENSE.txt`.
- ALIA: https://huggingface.co/datasets/SINAI/ALIA-es-discriminative-stance-detection

The datasets keep their original licences. Reference disagreements represent disagreements with the specified reference and are not always objective label errors. Source-evaluation labels, reference collection, multiple human votes and computation are separate from the record-level review budgets in the paper.
